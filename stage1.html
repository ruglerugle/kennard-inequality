STAGE 11927年の宿題
「ばらつき」を数学にする
🎯 ミッション
「だいたいの幅」だったΔを、誰が計算しても同じ値になる「標準偏差」で定義し直し、証明すべき定理を一つの式で言えるようになろう。
未達成
ねこ博士
量子力学の教室で、不確定性原理の正体を突き止めたのを覚えているかな。電子は波動関数 ψ で表される波で、位置の決まった「波束」を作るには、いろいろな波長の波を混ぜるしかない。そして波長は p＝h/λ で運動量に対応しているから、位置を絞るほど運動量がばらつく。ハイゼンベルクは1927年、思考実験からこのトレードオフを「Δx と Δp の積は、およそ h より小さくできない」と見積もった。
うさ美
覚えています。それで、あのときからずっと気になっていたことがあるんです。その式の Δx って、正確には何ですか？ 「位置のばらつきの幅」と言われれば分かった気になりますけど、「幅」の測り方は人によって違いそうです。端から端までを測る人もいれば、真ん中あたりの太さを測る人もいる。測り方が決まっていない量の不等式は、証明のしようがないと思うんです。
ねこ博士
素晴らしい着眼だよ。それこそが、1927年に物理学界に残された宿題そのものなんだ。ハイゼンベルクの論文の Δ は、実は「だいたいの幅」という曖昧なままだった。だから彼の主張は、正確には定理ではなく見積もりだ。これを定理に格上げするには、2つの問いに答えなければいけない。①「ばらつき」を、誰が計算しても同じ値になるように定義する。②その定義のもとで、積の下限が正確にいくつなのかを、どんな状態についても証明する。この宿題を同じ年のうちに片付けたのが、アメリカの物理学者ケナードだよ。今回のクエストでは、彼の定理の証明を、最後の1行まで自分の手でたどる。
うさ美
望むところです。でも①からして難問に見えます。「ばらつき」なんて、あやふやさの代名詞みたいな言葉なのに、それを数学にできるんでしょうか。
ねこ博士
実はね、ぴったりの道具が、量子力学が生まれる100年以上前から存在していたんだ。天文学者たちは昔から悩んでいた。同じ星の位置を何度測っても、結果が毎回すこしずつ違う。どの値を信じればいいのか、測定の「ぶれ」はどのくらい深刻なのか。この悩みに答えるために、数学者ガウスたちが19世紀はじめに誤差論という分野を作り上げた。測定値の散らばりを一つの数にまとめる方法が、そこにきちんと用意されていたんだよ。ケナードの最初の一手は、発明ではなく借用だった。星のばらつきのために作られた道具を、電子のばらつきに使ったんだ。
うさ美
言われてみれば、同じ構図ですね。星は「何度も測ると毎回違う値」、電子も「同じ状態を何個も測ると毎回違う値」。散らばりを数値にしたいという悩みまで同じです。その道具、どういう仕組みなんですか？
ねこ博士
実際に作ってみるのが早いね。小さな例でやってみよう。5回の測定で 3, 5, 5, 6, 6 という値が出たとする。平均は (3+5+5+6+6)÷5＝5 だ。ばらつきを測りたいから、まず各測定値の「平均からのずれ」を書き出してごらん。
うさ美
ずれは −2, 0, 0, +1, +1 です。……あ、これをそのまま平均したらダメですね。(−2＋0＋0＋1＋1)÷5＝0。プラスのずれとマイナスのずれが打ち消し合って、どんなにばらついていても答えが0になってしまいます。ずれの「符号」ではなく「大きさ」を見たいわけですから……絶対値をとってから足せばよさそうです。2＋0＋0＋1＋1＝4、5で割って 0.8。これで「ばらつきは 0.8」と言えませんか？
ねこ博士
いい筋だよ。それで正しく「ばらつき」を測れている。平均絶対偏差という名前もついていて、いまでも使われる立派な指標だ。……ただ、もうひとつ賢いやり方がある。絶対値の弱点はね、符号を消したところで話が終わってしまうことなんだ。|−2| は 2、それだけ。式のまま変形して先へ進む、ということができない。ところが2乗なら、符号を消したうえで展開できる。(a−b)²＝a²−2ab＋b² のようにね。同じ「符号消し」でも、2乗のほうは、そのあとの計算に使える形で消してくれるんだ。
うさ美
符号を消すだけなら、どちらでも同じ……。正直、「展開できる」ことがそこまで大事なのかは、まだ実感が湧きません。ただ、あとの計算に残せる形かどうかで選ぶ、という考え方は分かりました。2乗が選ばれた理由は、そこにあるんですね。
ねこ博士
そのとおり。ガウスたちが2乗を選んだのも、まさにその理由だよ。では実際に計算してみよう。ずれの2乗は 4, 0, 0, 1, 1。この平均 (4+0+0+1+1)÷5＝1.2 を分散と呼ぶ。ただし2乗したせいで単位が「点²」みたいになってしまうから、最後に平方根をとって単位を元に戻す。√1.2 ≈ 1.1。これが標準偏差――「ばらつきの幅」の世界標準の定義だ。いま言った「展開できる」という強みが、後のステージで証明そのものを動かすことになるよ。
標準偏差の作り方（レシピ）： ① 平均を求める　
② 各値の「平均からのずれ」を出す　
③ ずれを2乗する（符号を消す） ④ 2乗したずれを平均する（＝分散）　
⑤ 平方根をとって単位を戻す（＝標準偏差）
ねこ博士
これを量子の世界に持ち込もう。まったく同じ状態の電子を、たくさん用意する。半分のグループでは位置 x を測り、残り半分のグループでは運動量 p を測る。位置の測定結果の標準偏差、それが Δx。運動量の測定結果の標準偏差、それが Δp だ。これがケナードの定義だよ。曖昧さはもうどこにもない。状態（つまり波動関数 ψ）を決めれば、Δx も Δp もただ一つの値に決まる。
うさ美
定義ははっきりしました。……ただ、ひとつ素朴な疑問が。位置や運動量は、具体的にはどうやって測るんですか？ 電子は目に見えないのに。
ねこ博士
もっともな質問だ。どちらも実在する装置の話だよ。位置は簡単で、蛍光スクリーンや検出器にぶつけて、光った場所を読む。二重スリット実験でスクリーンに点が光ったね、あれだ。その点の座標が、その1個の測定値になる。……運動量のほうは2通りある。ひとつは磁場で曲げる方法。磁場の中では電荷を持った粒子は円を描いて曲がって、その半径は r＝p/(qB)（q は電荷、B は磁場の強さ）――勢いのある粒子ほど曲がりにくいから、半径を測れば p が出る。もうひとつは結晶に当てて、回折する角度を測る方法だ。角度から波長 λ が分かって、p＝h/λ で運動量になる。……こちらは面白くてね。きみが手がかりにした p＝h/λ が、そのまま測定装置として働いているんだよ。
運動量の測り方。① 磁場の中では電荷を持つ粒子が円を描いて曲がり、その半径は r＝p/(qB)。勢いのある電子ほど曲がりにくいので、半径がそのまま運動量の目盛りになる。② 結晶に当てると、規則正しく並んだ原子で回折して特定の角度に強く出る。その角度から波長 λ が分かり、p＝h/λ で運動量になる――ド・ブロイの式が、そのまま測定装置として働いている
うさ美
①の図で気になったことがあります。電子は最後にどこかへ当たって、その場所が分かりますよね。その座標を読めば、それは位置の測定値そのものじゃないですか。運動量を測る装置なのに、位置も同時に分かってしまう気がします。
ねこ博士
よく見ているね。そのとおりで、位置は分かる。……ただ、そこには落とし穴があってね。もう一度図を見てごらん。電子は左から右へ進みながら、上へ曲げられている。半径から求めているのは、電子が進んでいた向きの勢いだ。いっぽう「どれだけ曲がったか」を読むのは、それと直角の向きのずれだね。……向きが違うんだよ。そして私たちが証明しようとしている Δx·Δp ≥ ℏ/2 は、同じ向きの位置と運動量についての式なんだ。直角に交わる向きどうしの組には、この下限は掛からない。いくらでも正確に、同時に測っていい。
うさ美
なんだ、私が「両方測れている」と思ったのは、そもそも禁じられていない組み合わせだったんですね。……では、意地悪な質問をします。同じ向きで粘ったらどうなりますか。細いすき間を通してから測れば、進行方向の位置も絞れるはずです。そのうえで運動量を読めば――
うさ美の作戦。長く伸びた波を幅 Δx のすき間で切り取れば、電子のいる場所は Δx の中に絞れる。あとは残った切れ端の波長 λ を読んで p＝h/λ に入れれば、位置も運動量も同じ向きで手に入る――そう見える。ところが切れ端に残っている波は1個半ほどしかない。この短さで、波長は本当に読めるだろうか
ねこ博士
そこがこの話のいちばん面白いところだよ。②の結晶のほうで考えるとはっきりする。……まず、なぜ特定の角度だけ強く出るのか、そこから始めよう。結晶の中では原子がきれいな面をつくって、等間隔 d で何層も重なっている。電子の波は1枚目の面でも2枚目の面でも跳ね返るから、2枚目で跳ね返った波のほうが余分な道のりを進むことになるね。その余分な道のりは 2d sinθ だ。θ は面すれすれから測った角度で、sinθ は直角三角形で角度 θ に向かい合う辺を斜辺で割った割合のこと。いまは「角度が決まればひとつに決まる数」と思ってくれればいい。
ねこ博士
そして、その余分な道のりがちょうど波長1個分になったとき、2つの波は山と山がぴったり重なって強め合う。2d sinθ ＝ λ だね。「その角度で強く出る」というのは、それだけのことなんだ。
うさ美
分かりました。……では、角度が少しだけずれたらどうなりますか。余分な道のりがぴったり λ ではなく、λ より少し長くなったとき。少し弱くなるだけで、まだ明るいままな気がします。
ねこ博士
そこだよ。面が2枚だけならね、きみの言うとおり、ほとんど変わらない。……ところが面は2枚ではないんだ。余分な道のりのずれを δ とすると――1枚目と2枚目のずれは δ。1枚目と3枚目は 2δ。4枚目は 3δ。……ずれが積み重なっていく。そして積み上がったずれが全体で波長1個分になったとき、N枚の波は山から谷まで均等にばらけて、きれいに全部打ち消し合って消えてしまう。その条件は Nδ ＝ λ、つまり δ ＝ λ/N だ。
① 6枚の面から返ってきた波を縦に並べたもの。角度がぴったりなら6本は揃って強め合うが、1枚あたり λ/6 だけずれると、6本は山から谷まで均等にばらけて、合計はぴったり 0 になる。② 角度に対する明るさ。面が2枚なら山はゆるく広いが、12枚になると同じ物差しの上で山が一気に細くなる。面が多いほど「ぴったりの角度」の許容範囲が狭い＝角度が精密に決まる
うさ美
え、たった λ/N ですか。……面が1000枚あったら、1枚あたり波長の1000分の1 ずれただけで、明るさが消えてしまうということですよね。
ねこ博士
そう。……たとえで言おうか。N人が一列に並んで拍手をする。全員がぴったり揃えば、一発の大きな「パン！」になるね。ここで、各人がすぐ前の人より1000分の1秒だけ遅れるとしよう。2人だけなら、ずれは合わせて1000分の1秒。ほとんど揃って聞こえる。ところが1000人いると、最後の人は最初の人よりまるまる1秒遅れて、パンではなくザーッという広がった音になる。……同じ「1人あたりのわずかなずれ」が、人数が多いと致命傷になるんだ。
うさ美
裏返すと――長い列は、タイミングのずれをものすごく鋭く検出する装置になっているわけですね。面が多いということは、角度をそれだけ厳しく問うということ。
ねこ博士
よくまとめたね。では、きみの作戦に戻ろう。波が何枚の面にまたがるかは、波の広がり Δx で決まる。面の間隔が d なら N ≈ Δx/d だ。許される角度のずれは λ/N ＝ λd/Δx――つまり Δx を小さくすればするほど、許されるずれは大きくなる。角度がぼやけるんだよ。極端に、波が面1枚ぶんの幅しかなければ N ＝ 1。見比べる相手の面がいないから、打ち消し合いようがない。どの角度でも同じくらい出てしまって、角度は何も教えてくれなくなる。……これを p＝h/λ に入れると、運動量の読みのボケはおおよそ h/Δx になる。
うさ美
これから証明しようとしている関係が、装置の中から勝手に出てきているじゃないですか。……装置の出来が悪いからではないんですね。回折という現象が、位置の広がりを材料にして角度を作っている。材料を取り上げてしまえば、角度は出てこない。
ねこ博士
そのとおり。……ただ、ここで念を押しておきたいことがある。いま話したのは、どれも装置の話だ。ハイゼンベルクが1927年にやったのも、まさにこの種類の議論でね。ところがケナードの証明には、装置がひとつも出てこない。波の数学だけで ℏ/2 が出てくる。装置が下手だから測れない、ではなく――両方が狭い波そのものが存在しない。そこまで踏み込んだ話になるんだ。その違いがどれだけ大きいかは、旅の最後で確かめよう。……というわけで、位置を測る装置と運動量を測る装置は、別々に建てるしかない。
うさ美
装置そのものが別なんですね。しかもスクリーンに当たった電子はそこで吸収されてしまうから、そのあと磁場で曲げることはできない。1個で両方を測ることはできず、グループを分けるしかないわけです。……なるほど、測定が状態を乱すかどうかという話を、最初から避けているんだ。どの電子も測られるのは1回だけだから、「1回目の測定が2回目を乱した」という文句のつけようがない。これは測る前の状態そのものが持っているばらつきの話になっています。
ねこ博士
完璧な理解だよ。ハイゼンベルク自身の最初の説明は「測定が乱すから」という描像だったけれど、ボーアが指摘した通り、本質は波であることそのもの。ケナードの定義は、その本質だけをきれいに切り出しているんだ。さあ、定義が決まったから、証明すべきことも一つの式で書けるようになった。これが今回のクエストの頂上だよ。
【証明したい定理】
どんな波動関数 ψ に対しても：　Δx × Δp ≥ ℏ／2 Δx：
位置測定の標準偏差　Δp：運動量測定の標準偏差　ℏ＝h/2π ≈ 1.05×10⁻³⁴ J·s
同じ状態をたくさん用意して測定した結果の分布。標準偏差 Δ は「山の幅」を1つの数で表す。左のように分布が集中していれば Δ は小さく、右のように散らばっていれば大きい
うさ美
頂上がはっきり見えました。あとは Δx と Δp を波動関数 ψ から計算する式に直して、その積が ℏ/2 を下回れないことを、どんな ψ についても示せばいいんですね。……でも、「どんな ψ についても」って、波の形は無限にありますよ。全部を一つずつ調べるわけにはいきません。
ねこ博士
そこが数学の証明の凄みであり、面白さだよ。無限にある波を一網打尽にする論法が、ちゃんと存在するんだ。そのために次のステージから、道具を一つずつ手に入れていく。最初の道具は「積分」――といっても怖がらなくていい、正体は細かく切って足すだけの、素朴な足し算なんだ。
確認クイズ

Q1. 「平均からのずれ」をそのまま平均してもばらつきの指標にならないのはなぜ？

正解！ どんなにばらついた測定値でも、平均からのずれを全部足すと必ず0になる。だから2乗して符号を消してから平均する。これが分散、その平方根が標準偏差だ。

Q2. ケナードによる Δx の定義は？

正解！ Δx は測定器の性能でも1回の誤差でもなく、「測る前の状態そのものが持つばらつき」を標準偏差で測ったもの。状態 ψ を決めれば Δx はただ一つに決まる。

Q3. ハイゼンベルクの1927年の議論と、ケナードの定理の違いは？

正解！ ハイゼンベルクの Δ は「だいたいの幅」のままで、主張も「およそ h より小さくできない」という見積もりだった。ケナードは標準偏差で定義を固定し、どんな状態でも成り立つ定理 Δx·Δp ≥ ℏ/2 として証明したんだ。
